Transcription

Records 5 seconds of your voice, tries GPU, flash attention, decoding and thread options, and keeps the fastest one that gives the same text.

    While you hold a hotkey with Ctrl/Alt/Shift, the typed text can arrive with those modifiers. A single function key such as F9 avoids that.

    Needs a downloaded local model and an API key. Every recording is also sent to OpenAI. The result of the backend selected above is pasted; both show up under Home.

    Hotkeys

    On Wayland the hotkeys need permission to read the keyboard. This installs a small udev rule once and asks for your administrator password.
